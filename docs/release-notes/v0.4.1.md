# Dive Slate 0.4.1 — the app stops installing its own updates

If Android told you 0.4.0 was an **unsafe app** and blocked the install, this
release is why that happened and what was done about it. Nothing was wrong with
the build: it is signed with the same key as every release before it, and you can
check the APK below against its published checksum.

## What was actually going on

Until now the app did the whole update itself — asked GitHub whether a newer
version existed, downloaded the APK, verified it against the checksum in the
release, and handed it to Android's installer. To do the last part it had to
declare `REQUEST_INSTALL_PACKAGES`, the permission that lets an app ask to
install software.

That combination is, as *behaviour*, what a malicious downloader does: fetch a
binary from the network and install it. Play Protect scores behaviour rather than
intent, and a signing certificate it has never seen before, on a build with a
handful of installs, has nothing on the other side of the scale. So a correct
release gets classified as harmful.

The worse case is the one you cannot tap through: Google's enhanced fraud
protection blocks sideloading outright for apps declaring that permission. A
phone that cannot install is a phone that can never be updated again.

## What changed

The app still checks once a day whether a newer version exists — that is one
request to GitHub for a few hundred bytes, and the only thing it does with the
network. When there is one, it now **opens the release page in your browser**,
and the browser downloads the APK and hands it to Android. The browser is the
unknown source your phone asks about, which is the ordinary way software gets
onto a phone outside a store.

`REQUEST_INSTALL_PACKAGES` is gone from the app entirely. The only permission
left is internet access.

**What this costs you.** Two extra taps, and the app no longer verifies the
download for you — it cannot, because it never holds the file. The update banner
now prints the expected SHA-256 in full, and every release carries a `.sha256`
beside the APK, so the check is still available; it is just yours to make rather
than automatic.

## Installing this one

Download **`dive-slate-0.4.1.apk`** below and open it. **Android 10 or newer.**

If 0.4.0 was blocked on your phone, install this one straight from your browser
and the block does not apply — it is the app's own installer request that draws
the flag, not the file. If your phone still warns about an app from an unknown
developer, that is the ordinary sideload notice.

Same signing key as 0.3.0 and 0.4.0, so this updates in place and keeps your
settings.
