# Dive Slate 0.4.2 — same app, published to exercise the update path

**There is nothing new in this build.** It is identical to 0.4.1 apart from its
version number, and it exists so that a phone running 0.4.1 has something to be
offered — the update path 0.4.1 introduced cannot be tested without a newer
release to point at.

If you are on 0.4.1, the app should notice this within a day and offer to open
this page, where your browser downloads the APK and Android installs it. That
hand-off is the thing being tested. Installing this changes nothing else.

If you are arriving here for the first time, install this one: it is the current
version, and 0.4.1's notes describe what actually changed.

## Install

Download **`dive-slate-0.4.2.apk`** below and open it. **Android 10 or newer.**
`dive-slate-0.4.2.apk.sha256` holds its checksum. Same signing key as every
release since 0.3.0, so it updates in place and keeps your settings.

## Also attached

`update.json` is what the in-app check reads. `mapping-0.4.2.txt` is R8's
deobfuscation map, kept so a crash report from this build can still be read.
