# Dive Slate 0.4.3 — the app installs its own updates again

0.4.1 handed updating over to your browser: the app noticed a new version, opened
the release page, and left the download and install to Chrome. This release puts
the old way back. The app downloads the APK itself, checks it against the
checksum published in the release, and hands the verified file to Android's
installer — one tap from the banner, and a mismatched or truncated download is
refused rather than installed.

The hand-off worked, and it was given up on purpose. It cost two extra taps every
time, and it turned the checksum from something the app enforced into something
you were shown and left to check yourself. Neither is dramatic; both are worse,
every single update, than the thing they were avoiding.

## What they were avoiding, and what it means for you

To install anything the app must hold `REQUEST_INSTALL_PACKAGES`. An app that
downloads a binary and asks to install it looks — as behaviour — exactly like
malware doing the same, and Play Protect scores behaviour rather than intent. A
correctly signed release can therefore be met with **Unsafe app blocked**.

Nothing is wrong with the build when that happens. It is signed with the same key
as every release since 0.3.0, and `dive-slate-0.4.3.apk.sha256` below lets you
confirm you have the exact file this repository built.

**If you see it:** tap **More details**, then **Install anyway**.

**If your phone blocks the install with no way through**, that is Google's
enhanced fraud protection rather than the ordinary warning, and it cannot be
overridden. Download the APK from this page in your browser instead — the block
applies to the app asking to install, not to the file.

## Install

Download **`dive-slate-0.4.3.apk`** below and open it. **Android 10 or newer.**
Same signing key as every release since 0.3.0, so it updates in place and keeps
your settings.

If you are on 0.4.1 or 0.4.2, this is the last update those versions hand to your
browser. From 0.4.3 onward the app installs updates itself again.
